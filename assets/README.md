# Assets livrés

Un dossier par asset, généré par `tools/blender/cr_03_check_and_export.py` :

```
assets/<Catégorie>/CR_<Catégorie>_<Nom>/
  CR_<Catégorie>_<Nom>_V01.glb   GLB propre (textures intégrées, ni caméra ni lumière)
  textures/                      copie des textures utilisées
  fiche_technique.json / .md     dimensions, pivot, composants, matériaux
  preview.png                    image de présentation
```

Catégories : `Kitchen`, `Furniture`, `Building`, `Decor`, `Prop`. Une nouvelle version = `_V02.glb` dans le même dossier.
