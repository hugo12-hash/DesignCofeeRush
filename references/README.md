# Références

| Dossier | Contenu | Règle |
|---|---|---|
| `character/R15/` | Mannequin R15 exporté de Studio + mesures + planche | Ne jamais modifier les proportions. |
| `moodboard/` | Images d'ambiance **validées** (style, couleurs, formes) | Nommer `MB_<sujet>_<nn>.jpg`, ex. `MB_Comptoir_01.jpg`. Ajouter une ligne ci-dessous par image. |
| `existing-game/` | Captures du jeu actuel (ville, magasin, machines) | Nommer `GAME_<sujet>_<date>.png`. La capture de la ville est la référence artistique prioritaire. |
| `roblox/` | Liens et synthèse de la doc Roblox | Voir `docs/03_ROBLOX_TECHNIQUE.md`. |
